# M9 — Relatórios & BI — Implementation Tickets

Index of the per-use-case implementation tickets for [M9 — Relatórios & BI](../m9-relatorios-bi.md). All nine use cases fall in Roadmap Phase 7 — Visibilidade (doc §14); there's no internal build ordering beyond that phase, except that ticket 09 (`ExportReportUseCase`) is generic and depends on tickets 01–08 existing as export targets.

| # | Ticket | Phase | Responsibility |
|---|---|---|---|
| 01 | [Get Executive Dashboard](uc-01-get-executive-dashboard.md) | 7 — Visibilidade | Composed dashboard (revenue, CMV/margin, delinquency, critical stock, top products, target progress), < 3s budget. |
| 02 | [Get ABC Curve](uc-02-get-abc-curve.md) | 7 — Visibilidade | Product/customer classification by revenue share (A/B/C). |
| 03 | [Get Managerial DRE](uc-03-get-managerial-dre.md) | 7 — Visibilidade | Gross revenue, deductions, CMV, expenses by cost center, net result. |
| 04 | [Get Stock Turnover](uc-04-get-stock-turnover.md) | 7 — Visibilidade | Turnover rate per product; stalled-item detection. |
| 05 | [Get Commission Report](uc-05-get-commission-report.md) | 7 — Visibilidade | Commissions per salesperson/product/period, ready for payroll. |
| 06 | [Get Supplier Purchase Summary](uc-06-get-supplier-purchase-summary.md) | 7 — Visibilidade | Volume, value and average lead time per supplier. |
| 07 | [Get Fiscal Books](uc-07-get-fiscal-books.md) | 7 — Visibilidade | Entries/Exits/ICMS Assessment books, PDF + TXT. |
| 08 | [Get Assessed Taxes](uc-08-get-assessed-taxes.md) | 7 — Visibilidade | ICMS/IPI/PIS/COFINS/ISS totals per period. |
| 09 | [Export Report](uc-09-export-report.md) | 7 — Visibilidade | Generic PDF/Excel export, applied to any report above. |
